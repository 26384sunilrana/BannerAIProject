## Common Workflows

### Creating a Banner Quickly
```
Ctrl+N          → Create new banner
Add text        → Type headline
Add image       → Upload photo
Save            → Ctrl+S
Preview         → P key
Publish         → Publish button
```

### Copying Design from One Banner
```
Open banner 1   → Find in list
Ctrl+A          → Select all
Ctrl+C          → Copy (future feature)
Create banner 2 → Ctrl+N
Ctrl+V          → Paste
Edit/customize
```

### Undoing Multiple Changes
```
Ctrl+Z          → Undo last action
Ctrl+Z          → Undo 2nd last action
Ctrl+Z          → Keep pressing to undo more
Ctrl+Y          → If you go too far, redo
```

## Tips for Using Shortcuts

1. **Master one at a time** - Don't learn all at once
2. **Start with basics** - Ctrl+S, Ctrl+Z, Delete
3. **Practice regularly** - Use shortcuts even if slower at first
4. **Write them down** - Keep reference sheet nearby
5. **Customize if possible** - Some apps allow custom shortcuts

## Mac Users

If you're using Mac, replace:
- **Ctrl** → **Cmd**
- **Alt** → **Option**

Examples:
- Cmd + S (instead of Ctrl + S)
- Cmd + Z (instead of Ctrl + Z)
- Option + T (instead of Alt + T)

## Troubleshooting Shortcuts

**Shortcut not working?**
1. Make sure you're focused on editor (click canvas first)
2. Some browser extensions may block shortcuts
3. Try in a new tab
4. Check if your keyboard layout is correct
5. Some older browsers may not support all shortcuts
