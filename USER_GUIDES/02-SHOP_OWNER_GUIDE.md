## Getting Started

### 1️⃣ First Login

**Steps**:
1. Go to: `https://app.bannereditor.app`
2. Enter **email** and **password**
3. Click **Login**
4. Select your **shop** from dropdown (if multi-shop)
5. Enter **Shop Owner Dashboard**

### 2️⃣ Initial Setup

**Required Tasks**:
- [ ] Complete shop profile
- [ ] Add shop address
- [ ] Upload shop logo
- [ ] Set up team members
- [ ] Review subscription plan
- [ ] Configure shop settings

**Time Needed**: ~20 minutes

## Team Management

### View Team Members

**Steps**:
1. Click **Team** in left sidebar
2. See all team members
3. View role and status for each member

**Team Member Columns**:
| Column | Description |
|--------|-------------|
| Name | Full name |
| Email | Email address |
| Role | Sales Exec / User / SubUser |
| Status | Active / Inactive |
| Joined | Join date |
| Banners | # of banners created |
| Actions | Edit / Remove |

### Invite New Team Member

**Steps**:
1. Click **Team** → **Invite Member**
2. Fill in invitation form:
   - **Email**: Team member's email
   - **First Name**: First name
   - **Last Name**: Last name
   - **Role**: Select role (see roles below)

3. Click **Send Invitation**
4. Member receives email invitation
5. Member creates account and joins team

**Available Roles**:
| Role | Permissions | Best For |
|------|-------------|----------|
| **Sales Executive** | Create/edit banners, view analytics | Campaign managers |
| **User** | Create/edit own banners | Content creators |
| **SubUser** | Limited access | Assistants, interns |

### Edit Team Member Role

**Steps**:
1. Click **Team** → Find member
2. Click member's name
3. Click **Edit** button
4. Change **Role** from dropdown
5. Click **Save Changes**
6. Member receives notification

### Remove Team Member

**Steps**:
1. Click **Team** → Find member
2. Click **Remove** button
3. Confirm removal
4. Member loses access to shop
5. Member's banners remain (can reassign)

### SubUser Management

**What are SubUsers?**
- Assistants or helpers under Shop Owner
- Limited permissions (view only by default)
- Cannot create new banners
- Can help with content/media

**Create SubUser**:
1. Click **Team** → **Invite Member**
2. Select **SubUser** role
3. Send invitation
4. SubUser joins team

**Promote SubUser**:
1. Click **Team** → Find SubUser
2. Click **Edit**
3. Change role to **User** or **Sales Executive**
4. Click **Save Changes**

## Shop Settings

### Edit Shop Profile

**Steps**:
1. Click **Settings** → **Shop Profile**
2. Update shop information:
   - **Shop Name**: Display name
   - **Shop Description**: Short description
   - **Logo**: Upload shop logo
   - **Phone**: Shop phone number
   - **Website**: Shop URL

3. Click **Save Changes**

### Shop Address

**Steps**:
1. Click **Settings** → **Address**
2. Update address fields:
   - **Street Address**: Full address
   - **City**: City name
   - **State**: State/province
   - **Postal Code**: Zip code
   - **Country**: Country

3. Click **Save Changes**

### Shop Billing Address

**Steps**:
1. Click **Settings** → **Billing Address**
2. Enter billing address (same as shop or different)
3. Save address

**Note**: Billing address is used for invoices and receipts.

### Email & Notifications

**Steps**:
1. Click **Settings** → **Notifications**
2. Toggle notifications:
   - [ ] Daily digest email
   - [ ] Weekly performance report
   - [ ] Important alerts
   - [ ] Banner published notifications
   - [ ] Team activity updates

3. Click **Save Preferences**

## Billing & Subscription

### View Subscription Plan

**Steps**:
1. Click **Billing** → **Subscription**
2. See current plan details:
   - Plan name and price
   - Renewal date
   - Billing cycle
   - Included features
   - Usage statistics

### Upgrade Plan

**Steps**:
1. Click **Billing** → **Plans**
2. View available plans
3. Click **Upgrade** on desired plan
4. Review new price
5. Click **Confirm Upgrade**
6. New plan effective immediately
7. Prorated charges/credits applied

### Downgrade Plan

**Steps**:
1. Click **Billing** → **Plans**
2. Click **Downgrade** on lower-priced plan
3. Review downgrade details
4. **Warning**: Some features may be restricted
5. Click **Confirm Downgrade**
6. Effective at next renewal

**What Happens on Downgrade**:
- Exceeding banners: You have 30 days to reduce
- Exceeding storage: Files remain, no new uploads until under limit
- Exceeding team size: Cannot add new members until under limit

### View Invoices & Receipts

**Steps**:
1. Click **Billing** → **Invoices**
2. See all past invoices
3. Filter by: Date, Amount, Status

**Download Invoice**:
1. Find invoice in list
2. Click **Download PDF**
3. Invoice saved to computer

**Email Invoice**:
1. Find invoice in list
2. Click **Email**
3. Enter recipient email
4. Click **Send**

### Update Payment Method

**Steps**:
1. Click **Billing** → **Payment Method**
2. Click **Edit**
3. Update credit card:
   - Card number
   - Expiration date
   - CVV
   - Cardholder name

4. Click **Save Payment Method**

### Auto-Renewal Settings

**Steps**:
1. Click **Billing** → **Auto-Renewal**
2. Toggle **Enable Auto-Renewal** (ON/OFF)
3. Review renewal terms
4. If ON: Subscription automatically renews
5. If OFF: Get reminder, must manually renew

## Analytics & Performance

### View Shop Analytics

**Steps**:
1. Click **Analytics** in left sidebar
2. Select date range
3. View metrics:
   - Total banners created
   - Banners published
   - Banners in draft
   - Total views
   - Total clicks
   - Click-through rate (CTR)
   - Conversion rate

### View Individual Banner Analytics

**Steps**:
1. Click **Banners** → Find banner
2. Click banner name → **Analytics** tab
3. View banner-specific metrics:
   - Views (daily/weekly/monthly)
   - Clicks
   - Click locations (heatmap)
   - Device breakdown
   - Traffic source
   - Engagement over time

### Export Analytics Report

**Steps**:
1. Click **Analytics** → **Export**
2. Select report type:
   - Summary Report
   - Detailed Analytics
   - Team Performance

3. Select date range
4. Click **Generate Report**
5. PDF downloaded to computer

### Compare Banner Performance

**Steps**:
1. Click **Analytics** → **Compare**
2. Select 2-4 banners to compare
3. Choose metrics to compare
4. View side-by-side comparison

## Best Practices

### 👥 Team Management

✅ **DO**:
- Hire and empower a capable team
- Regular 1-on-1 check-ins
- Provide training and resources
- Recognize top performers
- Delegate appropriately

❌ **DON'T**:
- Overload team members
- Create unnecessary roles
- Remove permissions without explanation
- Ignore team feedback
- Make sudden changes

### 🎨 Banner Strategy

✅ **DO**:
- Test different banner designs
- A/B test variations
- Monitor performance metrics
- Update underperforming banners
- Keep content fresh

❌ **DON'T**:
- Set and forget
- Ignore analytics
- Publish without preview
- Use outdated designs
- Copy competitor designs directly

### 💰 Billing Management

✅ **DO**:
- Monitor usage vs. plan limits
- Plan upgrades in advance
- Review invoices promptly
- Keep payment method updated
- Track spending trends

❌ **DON'T**:
- Let subscription lapse
- Ignore renewal reminders
- Ignore storage warnings
- Make surprise changes
- Dispute legitimate charges

### 📊 Performance Optimization

✅ **DO**:
- Review analytics weekly
- Set performance targets
- Optimize poor performers
- Test new approaches
- Share insights with team

❌ **DON'T**:
- Ignore metrics
- Make decisions without data
- Stop testing successful campaigns
- Copy everything from competitors
- Ignore customer feedback

## Troubleshooting

### Q: Team member can't login
**A**:
1. Check if member's status is "Active"
2. If inactive, click Edit → Toggle Active
3. Ask member to check email for invitation
4. Resend invitation if needed
5. Member should click link in email to activate

### Q: Storage limit exceeded
**A**:
1. Click Analytics → Storage Usage
2. Find largest files
3. Delete unused media files
4. Or upgrade plan for more storage

### Q: Can't see teammate's banners
**A**:
1. Check teammate's role
2. If SubUser, they may have limited access
3. Upgrade SubUser to User role if needed
4. All users can see shop banners

### Q: Subscription renewal failed
**A**:
1. Click Billing → Payment Method
2. Update credit card
3. Click **Retry Payment**
4. Or contact support@bannereditor.app

### Q: How to change subscription billing cycle?
**A**:
1. Click Billing → Subscription
2. Cannot change billing cycle mid-term
3. At renewal date, you can change to monthly/annual
4. Or contact support for special requests
