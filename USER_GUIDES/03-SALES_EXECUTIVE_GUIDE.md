## Create Banners

### Start New Banner

**Steps**:
1. Click **Create Banner** (or + button)
2. Enter banner details:
   - **Banner Name**: Descriptive name
   - **Campaign**: Select campaign (optional)
   - **Width**: 1200px (default)
   - **Height**: 600px (default)
   - **Background Color**: Choose color

3. Click **Create**
4. Banner editor opens

### Add Components to Banner

**Component Types**:

#### 1. Text Component
**When to use**: Headlines, descriptions, CTAs

**Steps**:
1. Click **Text** in left toolbar
2. Click on canvas where you want text
3. Type your text
4. Text appears on canvas
5. Use right panel to format:
   - Font family
   - Font size
   - Color
   - Bold/Italic/Underline
   - Alignment (left/center/right)

#### 2. Image Component
**When to use**: Photos, product images, logos

**Steps**:
1. Click **Image** in toolbar
2. Click on canvas to place image
3. Click **Upload** in right panel
4. Select image file (PNG, JPG, WebP)
5. Drag corners to resize
6. Right-click to position precisely

#### 3. Video Component
**When to use**: Product demos, testimonials, tutorials

**Steps**:
1. Click **Video** in toolbar
2. Click on canvas to place video
3. Click **Upload** in right panel
4. Select video file (MP4, WebM)
5. Configure video properties:
   - Play controls (auto-play, loop)
   - Mute audio
   - Poster image (thumbnail)

#### 4. Graphics Component
**When to use**: Decorative shapes, icons, lines

**Steps**:
1. Click **Shape** in toolbar
2. Choose shape: Rectangle, Circle, Polygon, Line
3. Click on canvas to place
4. Customize:
   - Fill color
   - Stroke color
   - Stroke width
   - Opacity

### Arrange Components

**Move Component**:
- Click component → Drag to new position
- Or use arrow keys for precise movement

**Resize Component**:
- Click component
- Drag corner handles to resize
- Hold Shift to maintain aspect ratio

**Layer Management** (Z-Index):
1. Right-click component
2. Choose:
   - **Bring Forward** (move up 1 layer)
   - **Send Back** (move down 1 layer)
   - **Bring to Front** (top layer)
   - **Send to Back** (bottom layer)

3. Or use layer panel on right side

### Delete Component

**Steps**:
1. Click component to select
2. Press **Delete** key
3. Or right-click → **Delete**
4. Component removed from banner

## Edit & Manage Banners

### Save Banners

**Auto-Save**: Every 30 seconds automatically

**Manual Save**:
1. Click **Save** button (top toolbar)
2. Notification confirms save
3. Version created in history

**Save As Copy**:
1. Click **File** → **Duplicate Banner**
2. New banner created with "(Copy)" suffix
3. Edit copy independently

### Apply Effects

**Available Effects**:
- **Opacity**: Fade effect (0-100%)
- **Rotation**: Spin effect (0-360°)
- **Scale**: Zoom effect
- **Blur**: Blurring effect
- **Animation**: Movement and transitions

**How to Apply Effect**:
1. Click component to select
2. Click **Effects** tab on right
3. Click **+ Add Effect**
4. Choose effect type
5. Adjust parameters:
   - Duration (1-10 seconds)
   - Easing (linear, ease-in, ease-out)
   - Intensity/amount

6. Preview effect with play button
7. Click Save

### Setup Carousel

**What is Carousel**: Auto-rotating media sequence

**Use Cases**: 
- Multiple product images
- Testimonial videos
- Photo gallery
- Rotating offers

**Steps**:
1. Add a video or image component
2. Click **Carousel** tab on right
3. Click **Enable Carousel**
4. Click **+ Add Media**
5. Upload images/videos for carousel
6. Set rotation timing:
   - Time per item: 3-10 seconds
   - Auto-play: Yes/No
   - Loop: Yes/No

7. Click **Preview** to test
8. Save banner

## Publish Banners

### Preview Before Publishing

**Steps**:
1. Click **Preview** button (top toolbar)
2. Full banner displayed
3. Test all interactions
4. Click **Edit** to go back
5. Make changes if needed

### Submit for Approval

**If Shop has approval workflow**:

**Steps**:
1. Click **Publish** button
2. Select **Submit for Approval**
3. Add note for reviewer (optional)
4. Click **Submit**
5. Shop owner/manager reviews
6. You get notification when approved/rejected

### Publish Directly

**If you have publishing rights**:

**Steps**:
1. Click **Publish** button
2. Review publishing options:
   - [ ] Make live now
   - [ ] Schedule for later (pick date/time)

3. Click **Publish**
4. Confirmation message
5. Banner now live

### Schedule Publication

**Steps**:
1. Click **Publish** → **Schedule**
2. Select date and time
3. Click **Schedule Publication**
4. Banner scheduled
5. You get notification when published

### Unpublish Banner

**Steps**:
1. Find published banner in list
2. Click **Unpublish**
3. Confirm unpublishing
4. Banner removed from live
5. Banner saved as draft

## Track Performance

### View Banner Analytics

**Steps**:
1. Find banner in list
2. Click banner → **Analytics** tab
3. View metrics:

| Metric | Means | Good Target |
|--------|-------|-------------|
| Views | How many times shown | Higher is better |
| Clicks | User interactions | 1-5% of views |
| CTR | Click-through rate | 2-5% for ads |
| Conversions | Desired actions | Varies by goal |

### Performance Chart

**Steps**:
1. Click **Analytics** tab
2. Select date range (Today/Week/Month/Custom)
3. View chart with:
   - Views (blue line)
   - Clicks (orange line)
   - Conversions (green line)

### Compare Banners

**A/B Testing**:

**Steps**:
1. Create 2 versions of banner (e.g., different colors)
2. Publish both versions
3. Run for same time period
4. Compare analytics
5. Keep performing version
6. Delete underperformer

**What to Test**:
- Headline text
- Image vs. video
- Different colors
- Different CTAs
- Component positioning

## Tips & Tricks

### 🎨 Design Tips

**Color Strategy**:
- Use 3-5 colors maximum
- Ensure good contrast for readability
- Use brand colors
- Reserve bright colors for CTAs

**Typography**:
- Use 2-3 fonts maximum
- Larger text = more readable
- Minimum font size: 14px
- High contrast text vs. background

**Layout**:
- Keep design balanced
- Don't overcrowd
- Use white space effectively
- Group related elements

### ⚡ Performance Tips

**File Size**:
- Compress images (PNG/WebP)
- Optimize videos (under 50MB)
- Use CDN for faster loading

**Load Time**:
- Fewer large images = faster
- Lazy load videos (don't auto-play)
- Optimize component count (< 50)

### 🚀 Campaign Tips

**Planning**:
- Plan campaign timeline
- Define success metrics
- Test before full launch
- Monitor performance daily

**Optimization**:
- Update underperformers weekly
- Test variations
- A/B test new ideas
- Keep successful banners live

**Documentation**:
- Use descriptive banner names
- Add notes/descriptions
- Tag by campaign
- Archive old campaigns

## Troubleshooting

### Q: Image not uploading
**A**:
1. Check file size (< 50MB)
2. Check file format (PNG, JPG, WebP)
3. Check internet connection
4. Try different image
5. Contact support if persists

### Q: Video plays but no sound
**A**:
1. Check if "Mute" is toggled ON
2. Toggle off mute in carousel settings
3. Check video file has audio track
4. Try different video file

### Q: Can't publish banner
**A**:
1. If approval workflow: Wait for shop owner
2. If direct publish: Check user permissions
3. Ensure all required fields filled
4. Try saving and refreshing browser

### Q: Performance numbers look wrong
**A**:
1. Check date range selection
2. Ensure banner is fully published
3. May take 24hrs for full reporting
4. Check if banner is paused
5. Contact support for historical data

### Q: Carousel not rotating
**A**:
1. Check carousel is enabled
2. Verify timing > 0 seconds
3. Ensure multiple items added
4. Toggle auto-play ON
5. Check browser autoplay settings
