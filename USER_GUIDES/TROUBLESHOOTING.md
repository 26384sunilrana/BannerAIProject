## Login & Access Issues

### "Invalid email or password" error

**Solution**:
1. Check CAPS LOCK is OFF
2. Verify email spelling (no spaces)
3. If you forgot password:
   - Click **Forgot Password?**
   - Enter email
   - Check email for reset link
   - Create new password
4. Try again

**Still not working?**
- Email: support@bannereditor.app
- Provide: Email address used for account

---

### "Account locked" message

**Why**: Too many failed login attempts (5+)

**Solution**:
1. Wait 24 hours for auto-unlock, OR
2. Contact shop owner to unlock, OR
3. Click **Forgot Password?** to reset

**Prevention**: 
- Write down password securely
- Use password manager (LastPass, 1Password)

---

### "Cannot access this shop"

**Why**: You don't have permission

**Solution**:
1. Verify you're in correct shop (dropdown)
2. Check your role (ask shop owner)
3. If should have access:
   - Screenshot error
   - Email: support@bannereditor.app

---

### "Page won't load"

**Solution**:
1. Refresh page (F5)
2. Hard refresh (Ctrl + Shift + R)
3. Check internet connection
4. Try different browser (Chrome, Firefox, Safari)
5. Clear browser cache:
   - Chrome: Settings → Privacy → Clear browsing data
   - Firefox: History → Clear Recent History
6. Close and reopen browser
7. Try on different device

---

## Editor Issues

### Editor won't load / Shows blank canvas

**Solution**:
1. Wait 10 seconds (editor may be loading)
2. Refresh page (F5)
3. Hard refresh (Ctrl + Shift + R)
4. Close tab and reopen
5. Check internet connection
6. Try different browser
7. Check browser version (should be recent)
8. Disable browser extensions (AdBlock, etc.)

**Still blank?**
- Note your banner ID
- Email: support@bannereditor.app

---

### Slow / Laggy editor performance

**Why**: Usually browser or computer issue

**Solution**:
1. Close other browser tabs
2. Close other applications
3. Restart browser
4. Use different browser
5. Check internet speed (should be 5+ Mbps)
6. Disable browser extensions
7. Use desktop instead of laptop (better performance)

**If still slow**:
- Note your browser and OS
- Email: support@bannereditor.app

---

### "Cannot save" error

**Solution**:
1. Check internet connection
2. Wait 30 seconds (auto-save in progress)
3. Click Save again
4. Refresh page and try again
5. Try different browser

**Prevention**:
- Auto-save happens every 30 seconds
- Look for "Auto-saved" notification
- Don't close editor without saving first

## File Upload Issues

### Image won't upload

**Possible Causes & Solutions**:

| Symptom | Cause | Solution |
|---------|-------|----------|
| Upload button doesn't respond | Browser issue | Refresh, try different browser |
| "File too large" error | File > 50MB | Compress image or resize |
| "Unsupported format" error | Wrong file type | Use JPG, PNG, or WebP |
| Upload stuck | Network interrupted | Refresh and retry |
| Upload very slow | Large file + slow internet | Compress image first |

**Image Format Help**:
- ✅ JPG (.jpg, .jpeg) - Best for photos
- ✅ PNG (.png) - Best for graphics
- ✅ WebP (.webp) - Best quality, smallest size
- ❌ BMP, TIFF, SVG not supported

**How to Compress Image**:
1. Use online tool: TinyPNG.com
2. Or use Photoshop/GIMP
3. Target: < 2MB for web

---

### Video won't upload

**Possible Causes & Solutions**:

| Symptom | Cause | Solution |
|---------|-------|----------|
| "File too large" error | Video > 100MB | Compress video |
| "Unsupported format" error | Wrong format | Convert to MP4 or WebM |
| Upload stuck at 50% | Large file size | Compress or split video |
| Upload took 30+ mins | Network issue | Upload may still be processing |

**Video Format Help**:
- ✅ MP4 (.mp4) - Best compatibility
- ✅ WebM (.webm) - Smaller file size
- ❌ AVI, MOV, etc. not supported

**How to Compress Video**:
1. Use online tool: CloudConvert.com
2. Or use HandBrake (free)
3. Target: < 50MB for HD video

**Pro Tip**: For large videos, upload during off-peak hours (midnight-6am)

## Display Issues

### Text appears blurry or pixelated

**Solution**:
1. Check text font (use standard fonts: Arial, Helvetica)
2. Ensure font size ≥ 16pt
3. Check zoom level (should be 100%)
4. Try different browser
5. Restart browser

---

### Image quality looks poor

**Solution**:
1. Use higher quality image:
   - Minimum: 1920x1080 pixels
   - Better: 4000x2000 pixels
2. Replace with better photo:
   - Take new photo
   - Use stock photo site (Unsplash, Pixabay)
3. Avoid stretching image (drag corner, not side)
4. Preview on actual device

---

### Components overlapping incorrectly

**Solution**:
1. Use Layer management (right panel)
2. Click component and use "Bring Forward" / "Send Back"
3. Or drag layers in layer panel
4. Ensure no components are too close
5. Adjust position using arrow keys for precision

---

### Colors not showing correctly

**Solution**:
1. Check if opacity is 100% (not transparent)
2. Check background color isn't same as element color
3. Try different color
4. Try in different browser
5. Clear browser cache

## Publishing Issues

### Can't publish banner

**Possible Causes**:

| Error | Cause | Solution |
|-------|-------|----------|
| "Need approval" | Approval workflow enabled | Submit to manager |
| "Insufficient permissions" | User role issue | Contact shop owner |
| "Banner incomplete" | Missing required fields | Check all fields filled |
| "Publish button disabled" | Technical issue | Refresh and retry |

---

### Banner published but won't appear live

**Solution**:
1. Check banner status (should show "Published")
2. Wait 2-5 minutes (caching delay)
3. Hard refresh browser (Ctrl + Shift + R)
4. Check if banner is scheduled (set for future)
5. Check if banner is paused

**Still not appearing?**
- Note banner URL
- Email: support@bannereditor.app with link

---

### Shared link doesn't work

**Solution**:
1. Check URL is complete and correct
2. Paste exact URL from banner
3. Try in private/incognito window
4. Try different browser
5. Check if banner is published (not draft)
6. Ask shop owner if banner is restricted

## Account Issues

### Lost access to email / email bouncing

**Solution**:
1. Update email in settings:
   - Click profile → Settings
   - Update email address
   - Verify new email
2. Or contact shop owner:
   - Provide old email
   - Request email change
   - Verify identity

---

### Password reset link not working

**Solution**:
1. Check email spam folder
2. Wait 10 minutes (mail delay)
3. Request new reset link
4. Copy-paste link (don't click directly)
5. Try different browser
6. Reset password must be within 24 hours

---

### Cannot delete account

**Why**: Account may have:
- Active subscriptions
- Published banners
- Unpaid invoices

**Solution**:
1. Publish all drafts or delete them
2. Cancel any subscriptions
3. Pay any outstanding invoices
4. Then contact shop owner
5. Shop owner can delete your account

## Network & Connectivity

### "Connection lost" during work

**Solution**:
1. Your work is auto-saved (check for "Auto-saved" message)
2. Check internet connection
3. Reconnect to WiFi or data
4. Refresh page
5. Your banners should still be there

**Prevention**:
- Manual save (Ctrl+S) every few minutes
- Use wired internet for large uploads
- Upload during low-traffic times

---

### Uploads interrupted / incomplete

**Solution**:
1. Wait for upload to complete
2. Check file size:
   - Images: < 50MB
   - Videos: < 100MB
3. Check internet speed (5+ Mbps)
4. Try uploading smaller file
5. Try different file type

**Large File Upload Tips**:
- Upload during nighttime (less traffic)
- Use wired internet (faster than WiFi)
- Close other applications
- Don't turn off computer during upload
